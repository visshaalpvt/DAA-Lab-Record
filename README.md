Each folder `expN/` contains: `README.md` (Title, Aim, Algorithm, Input, Program, Output, Screenshot, Result, Time & Space complexity), the source code, `output.txt` and `output.png`.

Run any experiment: `cd expN && python3 solution.py` (Exp 50 is C: `gcc solution.c -o solution && ./solution`).
